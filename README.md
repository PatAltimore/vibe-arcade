# vibe-arcade
Website listing vibe coded games and apps.

[Vibe Arcade live site](https://pataltimore.github.io/vibe-arcade/)

## Deployment

The site is a static site deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

One-time setup: in the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
